# AIkokuin（AI刻印 質量入力）

LPG容器 質量入力アプリ（[lpg-weight-app](https://github.com/yochiai-creator/lpg-weight-app) v137）のコピーに、
**iPadのカメラで容器の刻印を読み取って入力する機能**を足したものです。
元アプリの機能（ロット登録・テンキー入力・成績表PDF・まとめて送信・採番表）はそのまま使えます。

- 元アプリの仕様・変更履歴: [docs/lpg-weight-app/](docs/lpg-weight-app/)（README・ARCHITECTURE・HANDOFF。中のIDやURLは**本番のもの**なので、このコピーでは使わない）
- 刻印読み取りのきまり: 共有ドライブ「刻印読み取り_運用一式」の共通ルール・容器種別判定リファレンス・W判定ルール（20kg/50kg）・字体リファレンスの要点を `gas/Kokuin.js` の `KOKUIN_SYSTEM` に入れています。あちらのルールが更新されたら、ここも合わせてください。

## 刻印の読み取り

入力画面の「📷 刻印を読む（カメラ）」を押すと、カメラの映像が出ます。

1. 刻印を枠に入れて容器を止めると、その1コマをサーバー（GAS）に送り、Claude API（画像AI）が刻印を読みます。
2. 読めた項目: 記号・容器番号・V（内容積）・W（容器自重）・総重量シール・TP・製造年月・容器種別・そのほかの刻印。
3. 容器番号が入力中のロットに1つだけ当てはまれば、その容器の質量入力に進みます。
   - 確からしさ「高」: すぐ入力します。
   - 「中」: もう一度読み、同じ番号なら入力します（番号が変われば止めて目視を求めます）。
   - 「低」（W検算が合わない等）、記号・容器種別がロットと違う、どのロットにもない: 自動では入れません。「〜で入力」ボタンか、テンキーで入力します。
4. 刻印の **W を質量の欄に先に入れます**。合っていれば **Enter だけで保存**、違えば数字を打ち直します（打つと先に入れた値は消えます）。W検算（W＋0.5＝シール）が合わないときは入れません。Wの末尾が反射で読めずシールが読めたときは、W＝シール−0.5 で入れます。
5. 保存した容器が写っているあいだは読み直しません。次の容器に替わると、また読みます。
6. 入力に使った読み取りは、スプレッドシートの「**刻印記録**」シートに1行ずつ残ります（入力のしかた: auto＝1回で決定／auto2＝2回読んで決定／button／photo）。

運用ルールに合わせて、読めない桁は「?」のまま返し、推測で埋めません（? が残る番号は入力に使いません）。年月は「月-年下2桁」（「7-26」＝2026年7月）として扱います。

### カメラ映像が使えないとき

Apps Script のウェブアプリは Google の枠（iframe）の中で動くため、iPad・ブラウザの設定によってはカメラ映像（getUserMedia）が許可されないことがあります。
そのときは自動で「📷 写真を撮って読む」に切り替わり、1枚撮るたびに読みます（容器番号・Wの扱いは同じ）。

### 費用と速さ

- モデルは `claude-opus-5-5`（スクリプトプロパティ `KOKUIN_MODEL` で変更可）。1枚あたり画像約1,500トークン＋出力（考える分を含む）で、およそ1〜3円の見込みです（実際の値は Claude Console の使用量で確認してください）。
- 止まった容器ごとに1回（「中」なら2回）送ります。読めない場面は2回でやめ、場面が変わるまで送りません。
- 1回の読み取りに数秒かかります。

## セットアップ（コピーの手順に追加するもの）

基本は元アプリの引き継ぎ書「コピーの手順」と同じです（新しいスプレッドシート＋新しいGASプロジェクト＋新しいデプロイ）。このリポジトリでは、本番のIDはすでに外してあります。

1. 新しいスプレッドシートを作る（`setup/LPG容器_質量入力.xlsx` をドライブに上げて「Googleスプレッドシートとして保存」）。
2. 「拡張機能 > Apps Script」を開き、スクリプトIDを `.clasp.json` の `scriptId` に入れる（済み: `1zMP914N…`）。
3. テストを通す。

   ```bash
   npm install
   ```

   ```bash
   npm run check && npm test
   ```

4. 反映する。

   ```bash
   clasp push --force
   ```

5. スプレッドシートを開き直し、メニュー「LPG容器検査 > 初期セットアップ」を実行する（スクリプトプロパティ `SPREADSHEET_ID` が入る）。
6. **Claude APIキーを入れる**: Apps Script の「プロジェクトの設定 > スクリプト プロパティ」に `ANTHROPIC_API_KEY` を追加する（コードやシートには書かない）。
7. 「デプロイ > 新しいデプロイ > ウェブアプリ」（実行: 自分、アクセス: 組織内）。URLを iPad の Safari で開き、カメラの使用を許可する。
8. 必要なら、デプロイ後に `gas/Code.js` の `MAIN_SCRIPT_ID`・`MAIN_WEBAPP_URL` に**このコピーの**値を入れる（空のままなら旧URL案内は出ません。**本番のIDは入れないこと**）。

### 本番（lpg-weight-app）から変えたところ

| 場所 | 本番 | このコピー |
|---|---|---|
| `.clasp.json` scriptId | 本番のスクリプトID | このコピーのスクリプトID `1zMP914N…`（2026-11-20 設定） |
| `Code.js` MAIN_SCRIPT_ID / MAIN_WEBAPP_URL | 本番の値 | 空（旧URL案内を出さない） |
| `Code.js` DEFAULT_SPREADSHEET_ID | 本番のスプレッドシート | 空（初期セットアップの `SPREADSHEET_ID` かバインド先を使う） |
| ドライブのフォルダ・ファイル名 | LPG容器 質量入力 / LPG容器 採番表_ / LPG容器 入力記録_ / LPG容器 神鋼機器用 質量データ | AI刻印 〜 にそろえた（本番のフォルダを名前で見つけて使わないため） |
| 画面の題名 | LPG容器 質量入力 v137 | AI刻印 質量入力 AIkokuin v1 |

本番だけの一回きりの移行処理（Archive.js の RETIME_1021_SKIP、Delivery.js の SAIBAN_SENT_UNTIL・migrateCustomerFormat_ など）はそのまま残っています。空のスプレッドシートでは何もしません。
