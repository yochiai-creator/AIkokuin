# AIkokuin（AI刻印 質量入力）

LPG容器 質量入力アプリ（[lpg-weight-app](https://github.com/yochiai-creator/lpg-weight-app) v137）のコピーに、
**iPadのカメラで容器の刻印を読み取って入力する機能**を足したものです。
元アプリの機能（ロット登録・テンキー入力・成績表PDF・まとめて送信・採番表）はそのまま使えます。

- 元アプリの仕様・変更履歴: [docs/lpg-weight-app/](docs/lpg-weight-app/)（README・ARCHITECTURE・HANDOFF。中のIDやURLは**本番のもの**なので、このコピーでは使わない）
- 刻印読み取りのきまり: 共有ドライブ「刻印読み取り_運用一式」の共通ルール・容器種別判定リファレンス・W判定ルール（20kg/50kg）・字体リファレンスの要点を `gas/Kokuin.js` の `KOKUIN_SYSTEM` に入れています。あちらのルールが更新されたら、ここも合わせてください。

## 刻印の読み取り

ホーム画面または入力画面の「**🎬 撮って読む**」で iPad のカメラが開くので、ラインの容器を**動画**で撮ります（1本だけなら写真でも可）。撮り終わると自動で読み、一覧が出ます。

撮ってあるものは「📂 選ぶ」から。**タイムラプス（インターバル撮影）の動画**や、**一定間隔で撮った写真をまとめて選ぶ**こともできます（写真は撮った時刻→ファイル名の順に並べて、動画と同じように容器ごとにまとめる）。iPad のカメラアプリの「タイムラプス」で撮った動画は「📂 選ぶ」から選んでください。

Apps Script の画面は Google の枠の中で動くため、iPad ではカメラ映像を直接使えません（NotAllowedError）。そのため「撮ってから読む」方式です。

### 自動撮影カメラ「LPG刻印カメラ」（刻印が枠を通ったら撮る）

AIkokuin の画面では iPad のライブ映像が使えないため、撮影専用のページを別に用意しています（`docs/camera/index.html`、GitHub Pages で公開）。

- URL: `https://yochiai-creator.github.io/AIkokuin/camera/`（AIkokuin の入力画面の「📷 自動撮影」からも開ける）。Safari で開いて「ホーム画面に追加」するとアプリのように全画面で使える。
- 撮り方は ⚙ で2つから選ぶ（既定は「流れる」）。
  - **流れる**（止まらずに流れるライン）: 枠を**刻印が通る位置**に、刻印の文字がちょうど収まるくらいの大きさで合わせる。枠に刻印がないときに「▶ 開始」（最初の1秒で「ふだんの様子」を覚える）。刻印が枠を通るたびに、通過中で一番良いコマ（模様が多い＝刻印が写っている、刻印が枠の真ん中、ぶれが少ない）を1本あたりの枚数ぶん撮る。
    - しくみ: 枠の中の細かい模様の量を毎コマ（1秒に約30コマ）測り、直近5秒のふだんの値の1.25倍（感度5のとき）を超えたら「通過中」。現場の写真では刻印にぴったりの枠が塗装だけのときの1.34〜1.73倍だった。
    - 床のすき間や光った肩で余分に撮れることはあるが、読み取り側で「読めない」「同じ番号」としてまとめられる（撮り逃すよりよい）。撮りすぎるときは感度を下げる、逃すときは上げる。
  - **止まる**（台で止まるライン）: 容器が止まる台の上を枠で囲み、台を空にして「▶ 開始」。容器が入って止まると撮り、どくか次の容器に替わるまで同じ容器は撮らない。
- **刻印の型**（⚙「容器の種類」）: 神鋼機器工業の「小型容器刻印配置図」（5kg HRH・8kg HXU・10kg HCY・20kg HXC・20kg三部制 HHL・30kg HAM・50kg HEA・50kg S付 HHZ、40kg HDF は配置図がないので標準の並び）をもとに、黄色い枠の中に刻印の並びを「下にふくらむ弧」で半透明に描く。
  - 標準2段（20kg以外）: 上の段「LPガス V値 TP3.0M」、下の段「記号 番号 W値 年月」、その上に「※ ◇」。
  - **20kg**（図番31SM7247）: 3段とも同じ中心の弧で、両端が急に上がる。外の段「記号 番号 年月 TP3.0M」、真ん中「LPガス W値」、内「※ ◇ V 47」。記号は現行の **HXP**（配置図の見本 HXC は過去の世代）。
    - 言葉ごとの角度は、**現場で真上から撮った写真**（20kg HXR 15185、2026-11-21）から求めた。真上からは弧がつぶれずに写り、段の半径の比も型と同じ。全体の回り（約7°）を除くと配置図とほぼ同じ並びだった（横から撮った HXP 68462 の写真では斜めのぶん両端が広がって見えていたので、そちらは使わない）。
    - 現場の写真（640×360）を横に流す確認で、001・030・080・120 の4本とも1回の通過で1本・2枚撮れた（枠は 001 に手で合わせたまま）。
    - 20kg の写真は下から見上げるように撮られていて、刻印の弧が上下に**0.55倍ほどつぶれて**写っていた。こういうときは枠の高さを手で縮めて合わせる（「🎯 自動で合わせる」は、20kg の写真では合わなかった。縦のつぶれ具合も探すようにしてみたが、50kg の写真で間違いが増えたのでやめた）。
  - 弧の曲がり具合は現場の写真（50kg HEP 36815）で合わせた。映像の刻印に型が重なるように枠を動かし、大きさを合わせる（種類を選ぶと枠が型の縦横に合う）。
  - 判定は**型の文字が通る帯の中だけ**で模様を測る（枠の隅の床や反射に反応しにくい）。
  - **🎯 自動で合わせる**（下のボタン）: 型をだいたい刻印に重ねてから押すと、型の位置・大きさ・傾きを細かく合わせる（型の文字の帯の中の模様 − すぐ外の模様 が一番大きくなる所を、粗い地図と細かい地図の両方で探す（20kg の実物ではまだ確かめていない）。シールの黒い印刷や光った反射は数えない）。合わなければ「↩ 元に戻す」。⚙「型の傾き」で手でも傾けられる。
    - 現場の写真での確認（2026-11-21）: 1枚目（HEP 36815）は4通りの始め方のうち3通りで正しく合った。5枚目（HEP 37439、斜めから撮影）は刻印の曲がり方が型より浅く、**1段ずれた位置に合ってしまう**。打刻は淡いので、写真だけから必ず正しく合わせることはできない。最後は目で確かめる。
    - ⚙「自動補正」をオンにすると、撮るたびに上下・大きさ・傾きを少しずつ（1回で傾き2°・大きさ5%・上下は枠の高さの1割まで）合わせ直す。反射の多い所では型がずれていくことがあるので**既定はオフ**。
- LPG容器の刻印向けの工夫:
  - **反射を避ける**: 枠の中で真っ白に飛んだ（光った反射の）部分が多いコマは選ばない（刻印の読み違いのほとんどは反射が原因: 運用ルール）。見張り中に反射が多いと「角度や照明を変えて」と出る。
  - **保存する範囲**（白い点線）: 刻印・総重量シール・キャップが入る範囲だけを縮めずに保存する（既定は刻印の枠を左右に35%・上に1.2倍・下に0.4倍広げた範囲。点線を動かせば自由に変えられ、⚙「点線を刻印の枠に合わせ直す」で戻る）。文字が大きく写り、読み取りの画像も小さくなるので正確で安い。AIkokuin は AIK_*.jpg を切らずにそのまま読む。⚙ で「画面全体」にもできる。
  - **ズーム・ライト**: iPad が対応していれば ⚙ に出る。
  - 撮った本数・枚数を下に出す。小さな写真をタップすると大きく見られる（刻印が読める写りか、その場で確かめる）。
- 1本あたりの枚数は既定2枚（⚙ で1〜4枚）。2枚以上あると、AIkokuin の速読の2コマ一致で確定しやすく安く済む。
- 「📤 写真に保存」→ 共有シートの「◯枚の画像を保存」で写真アプリへ → AIkokuin の「📂 選ぶ」でまとめて選ぶと読み取る（写真には撮影日時を1秒未満まで書き込むので、撮った順に並ぶ）。
- 撮影中は画面がスリープしない（Wake Lock）。ためておけるのは400枚まで（iPadのメモリのため）なので、こまめに保存する。写真はこのページの中（iPadのメモリ）にだけあり、どこにも送らない。保存前にページを閉じると消える。

**公開のしかた（最初に1回）**: GitHub のリポジトリの Settings > Pages で、Source を「Deploy from a branch」、Branch を `claude/affectionate-curie-5grll6`（main に取り込んだ後は main）、フォルダを `/docs` にして Save。数分で上の URL が開けるようになる。

### 市販の動体検知カメラアプリを使う場合

市販のアプリで撮った写真も「📂 選ぶ」で同じように読める。横長（16:9）・1本につき2〜3枚・検知範囲は台の上だけ、がおすすめ。写真に撮影日時（Exif）がなければファイル名の順に並べる。

### 読み方（2段階で、安く正確に）

1. **コマ選び**（iPadの中・無料）: 動画は再生しながら**全コマ**を（タイムラプスで1本が数コマしか写らなくても取りこぼさない。長い動画は最大2400コマに間引く）、写真は1枚ずつ見て、場面（容器）が替わるところで区切り、各場面で一番くっきりしたコマを選ぶ。横長の動画は中央（左右10%・下15%を除く）を縮めずに使う。
2. **速読**: 選んだコマを1枚ずつ **Claude Haiku 5.5**（安い）で読む。同時に3つずつ。
3. **まとめ**: 時刻順に並べ、同じ番号が続いたコマを1本の容器にまとめる。
4. **確定**: 次をすべて満たす容器は速読だけで確定する。
   - 2コマ以上で番号もWも一致し、「低」がない
   - シールとのW検算（W＋0.5＝シール）がOK
   - キャップの手書きグループNoが一致する（キャップが見えなければ3コマ以上一致）
5. **精読**: 確定できない容器だけ、その容器の一番くっきりした3コマをまとめて **Claude Opus 5.5** で読み直す（運用ルールの「3枚組を見比べ、桁ごとに反射の少ないコマで確定」と同じ考え方）。
6. **一覧で確認して保存**: 写真（タップで拡大）と読みを見て、チェックした分を「保存」。刻印のWを質量として保存し、「刻印記録」に `video` / `photo` で残る。

最初からチェックが付くのは、確定した（速読で確定、または精読で「高」）・ロットに当てはまる・未入力・Wあり・W検算NGでない・種別違いでない・重複でない容器。Wがロットの標準から離れている（中央値±0.5kg、入れ始めは標準質量±1.5kg）ものは、チェックしても保存しません。

運用ルールに合わせて、読めない桁は「?」のまま返し、推測で埋めません。年月は「月-年下2桁」（「7-26」＝2026年7月）。読み取りのきまりは `gas/Kokuin.js` の `KOKUIN_SYSTEM` にあり、共有ドライブ「刻印読み取り_運用一式」の要点を写しています（あちらが更新されたら合わせる）。

### 費用

- 読み終わると一覧の上に「費用 約○円（速読 ○回・精読 ○回）」が出ます（API の使用量から計算した目安）。
- 目安: 速読 1コマ 約0.1円、精読 1本 約2〜4円。速読で確定できる容器が多いほど安くなります。
- 毎回同じルール文はキャッシュするので、2回目以降はその分が1/10の料金。
- モデルはスクリプトプロパティ `KOKUIN_MODEL_FAST`（速読）・`KOKUIN_MODEL`（精読）で変えられます。

## セットアップ（コピーの手順に追加するもの）

基本は元アプリの引き継ぎ書「コピーの手順」と同じです（新しいスプレッドシート＋新しいGASプロジェクト＋新しいデプロイ）。このリポジトリでは、本番のIDはすでに外してあります。

1. 新しいスプレッドシートを作る（`setup/LPG容器_質量入力.xlsx` をドライブに上げて「Googleスプレッドシートとして保存」）。
2. 「拡張機能 > Apps Script」を開き、スクリプトIDを `.clasp.json` の `scriptId` に入れる（済み: `1zMP914N…`）。
3. テストを通す。

   ```bash
   npm install
   ```

   ```bash
   npm run check && npm test
   ```

4. 反映する。

   ```bash
   clasp push --force
   ```

5. スプレッドシートを開き直し、メニュー「LPG容器検査 > 初期セットアップ」を実行する（スクリプトプロパティ `SPREADSHEET_ID` が入る）。
6. **Claude APIキーを入れる**: Apps Script の「プロジェクトの設定 > スクリプト プロパティ」に `ANTHROPIC_API_KEY` を追加する（コードやシートには書かない）。
7. 「デプロイ > 新しいデプロイ > ウェブアプリ」（実行: 自分、アクセス: 組織内）。URLを iPad の Safari で開き、ホーム画面に追加する。
8. 必要なら、デプロイ後に `gas/Code.js` の `MAIN_SCRIPT_ID`・`MAIN_WEBAPP_URL` に**このコピーの**値を入れる（空のままなら旧URL案内は出ません。**本番のIDは入れないこと**）。
